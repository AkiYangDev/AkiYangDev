# Repository guidance

This repository hosts AkiYangDev's GitHub profile. README.md is displayed publicly on the profile.

## Profile style

- Keep the profile concise, professional, and factual.
- Preserve the English and Chinese introduction and keep their meaning aligned.
- Do not add learning roadmaps, current-focus lists, future plans, beginner framing, or growth slogans unless explicitly requested.
- Do not invent expertise, achievements, employment details, project results, or contribution records.
- Add project links only after confirming that the public destination exists.
- Do not publish private contact details or workplace information without explicit authorization.

## Scope and workflow

- Keep changes focused on the requested task. This is a profile repository, not a technical article archive.
- Read the current file before editing; preserve unrelated user changes.
- Small authorized profile edits may go directly to main. Use a branch and PR for substantial changes when appropriate.
- Never force-push or change access permissions as part of a content edit.
- Use concise commit messages describing the actual change.

## Verification

- Preserve UTF-8 encoding, LF line endings, and a final newline.
- Review the Markdown rendering after layout changes.
- Check the Profile checks workflow for the submitted commit; distinguish a pending check from a passed check.
- Report what changed and any verification that could not be completed.
